# QDRM - Quantum Diffusion Restoration Model for Degraded Brahmi Characters

Code and executed results for the manuscript **"A Quantum Diffusion Framework for
Reconstruction of Degraded Brahmi Characters"** (Physica Scripta, manuscript
PHYSSCR-150398, under revision).
## Data sources

- Brahmi character dataset: https://www.kaggle.com/datasets/gautamneha/brahmi-dataset
- Authentic inscription (TBSI_006) original/annotated crops: K. Wakode,
  Mendeley Data, https://data.mendeley.com/datasets/mjm6shrjfh/1
